Read the estimate correctly

Educational estimate from saved listing data—not a live valuation or buying recommendation. Asking prices are not sale prices, dealer rating is not vehicle condition, and the model omits trim, location, options, accident history, and market changes.

Evaluation uses one deterministic random 80/20 holdout. It does not measure future-market performance or accuracy on models absent from the dataset.

Dataset: USA Mercedes Benz Prices Dataset by Danish Ammar, version 1, Apache-2.0. The checked-in data reshapes the original name and mileage fields.
